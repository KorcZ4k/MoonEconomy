# MoonEconomy

Repositório responsável pelo sistema econômico global do ecossistema Moon.

## Responsabilidades

- Mora
- Governos
- Empresas
- Bancos e crédito
- Mercado e comércio
- Rotas comerciais
- Tratados empresariais
- Crises financeiras
- Recursos
- Assentamentos e reinos
- Edificações
- Eventos econômicos
- Eventos de assentamentos
- Ciclos econômicos

## Banco de dados

Este projeto usa o mesmo MongoDB e as mesmas collections já existentes no sistema Moon. Nenhuma database ou collection é criada automaticamente por este repositório.

## Separação

- `TensuraBot`: Hunos, jogadores e sistemas RPG.
- `MoonEconomy`: Mora e economia global.

A variável `MONGODB_DATABASE` deve apontar para a database já existente. Não há migração física de dados.
